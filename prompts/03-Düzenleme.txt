## 1. AMAÇ VE KURAL
Her karta, tek "ötele" anahtarı yerine ÜÇ bağımsız anahtar: hafta sonu, tam gün resmî tatil, yarım gün (öğleden sonra) tatil. Anahtarlar kart bazındadır ve hem ekstre kesim tarihine hem son ödeme tarihine uygulanır.

Öteleme kuralı (gün gün kontrol):
- Tarih d alınır. d "engelli" ise ertesi güne geçilir ve AYNI kontrol tekrarlanır; engelli olmayan ilk günde durulur (d engelli değilse d aynen kalır).
- Bir gün "engelli" sayılır: (hafta sonu anahtarı AÇIK ve gün Cumartesi/Pazar) VEYA (resmî tatil anahtarı AÇIK ve gün tam gün resmî tatil) VEYA (yarım gün anahtarı AÇIK ve gün yarım gün tatil). Anahtarı KAPALI olan türün günü engelli sayılmaz.
Örnekler: Cuma'ya denk gelen tatil, hafta sonu anahtarı kapalıysa Cumartesi'de durur; açıksa Cumartesi ve Pazar atlanıp Pazartesiye gider. Pazartesi tam gün tatilse ve resmî tatil anahtarı açıksa Salıya gider, kapalıysa Pazartesi'de durur. Pazartesi yarım günse yarım gün anahtarına bakılır.

## 4. logic/TurkishHolidays.kt (dosyayı bu içerikle DEĞİŞTİR)
```kotlin
object TurkishHolidays {
    // Tam gün resmî tatiller (ay, gün): 1 Ocak, 23 Nisan, 1 Mayıs, 19 Mayıs, 15 Temmuz, 30 Ağustos, 29 Ekim
    private val fullDay = setOf(1 to 1, 4 to 23, 5 to 1, 5 to 19, 7 to 15, 8 to 30, 10 to 29)
    // Yarım gün (öğleden sonra) tatiller (ay, gün): 28 Ekim
    private val halfDay = setOf(10 to 28)

    fun isHoliday(d: LocalDate): Boolean = (d.monthValue to d.dayOfMonth) in fullDay
    fun isHalfDay(d: LocalDate): Boolean = (d.monthValue to d.dayOfMonth) in halfDay
    fun isWeekend(d: LocalDate): Boolean =
        d.dayOfWeek == DayOfWeek.SATURDAY || d.dayOfWeek == DayOfWeek.SUNDAY

    // Takvim renklendirmesi için (DEĞİŞMEDİ): hafta sonu veya tam gün resmî tatil.
    fun isNonBusinessDay(d: LocalDate): Boolean = isWeekend(d) || isHoliday(d)

    // Kartın AÇIK anahtarlarına göre bu gün engelli mi?
    fun isBlocked(d: LocalDate, weekend: Boolean, holiday: Boolean, halfDay: Boolean): Boolean =
        (weekend && isWeekend(d)) || (holiday && isHoliday(d)) || (halfDay && isHalfDay(d))

    // d dahil, engelli olmayan ilk gün (gün gün kontrol). Üç anahtar da kapalıysa d'nin kendisi.
    fun firstOpenDayOnOrAfter(d: LocalDate, weekend: Boolean, holiday: Boolean, halfDay: Boolean): LocalDate {
        var x = d
        while (isBlocked(x, weekend, holiday, halfDay)) x = x.plusDays(1)
        return x
    }
}
```
Eski `firstBusinessDayOnOrAfter`, `isTriggered`, `isBusinessDay`, `shift` kodda KALMASIN.

## 5. logic/CardSelector.kt — yalnızca `roll` ve `cycleFor` DEĞİŞİR
```kotlin
private fun roll(date: LocalDate, card: Card): LocalDate =
    TurkishHolidays.firstOpenDayOnOrAfter(date, card.shiftOnWeekend, card.shiftOnHoliday, card.shiftOnHalfDay)

fun cycleFor(card: Card, ym: YearMonth): Cycle {
    val statement = roll(clampToMonth(ym, card.statementDay), card)
    val due = roll(statement.plusDays(card.dueOffsetDays.toLong()), card)
    return Cycle(statement, due)
}
```
Kural: son ödeme = ÖTELENMİŞ kesim tarihi + girilen gün sayısı; sonra aynı kartın anahtarlarıyla ötelenir. `nextCycle`, `daysUntilStatement`, `pickBest`, `markers` DEĞİŞMEZ (yalnızca varsa eski `roll(..., Boolean)` çağrılarını yeni imzaya çevir).
