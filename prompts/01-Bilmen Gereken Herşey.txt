## 5. İŞ MANTIĞI (CardSelector.kt, saf Kotlin, Android bağımlılığı yok)
Model: `data class Card(val id: String, val name: String, val statementDay: Int)` (id = UUID metni, statementDay 1..31).

Kural: Ekstre kesim günü X olan kartta ayın X. günü yapılan harcama MEVCUT dönemdedir; yeni dönem X+1. gün başlar.

Kesin algoritma:
```kotlin
fun clampToMonth(ym: YearMonth, day: Int): LocalDate =
    ym.atDay(minOf(day, ym.lengthOfMonth()))

fun nextStatementDate(today: LocalDate, day: Int): LocalDate {
    val thisMonth = clampToMonth(YearMonth.from(today), day)
    return if (!thisMonth.isBefore(today)) thisMonth
           else clampToMonth(YearMonth.from(today).plusMonths(1), day)
}

fun daysUntilStatement(today: LocalDate, day: Int): Long =
    ChronoUnit.DAYS.between(today, nextStatementDate(today, day))

fun pickBest(cards: List<Card>, today: LocalDate): Card? {
    var best: Card? = null
    var bestDays = -1L
    for (c in cards) {            // eklenme sırasıyla gez
        val d = daysUntilStatement(today, c.statementDay)
        if (d > bestDays) { best = c; bestDays = d }   // yalnızca KESİN büyükse değiştir (eşitlikte ilk eklenen kalır)
    }
    return best
}
```
Açıklama: en uygun kart, bir sonraki ekstre kesim tarihi bugünden en uzak olan karttır. Ay sonu: kesim günü o ayda yoksa (örn. 31, Şubat) kesim ayın son günüdür. `object CardSelector` içinde bu 4 fonksiyonu yaz. "Bugün" = `LocalDate.now()` (cihaz yerel tarihi).
